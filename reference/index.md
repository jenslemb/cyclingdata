# Package index

## Data

- [`cyclingdata`](https://jenslemb.github.io/cyclingdata/reference/cyclingdata.md)
  : A comprehensive dataset on stage-races in professional cycling

## Scrape cycling data

- [`cyclingscraper()`](https://jenslemb.github.io/cyclingdata/reference/cyclingscraper.md)
  : Scrape cycling data from procyclingstats.com.

## Internal functions

These functions are used internally by `cyclingscraper`. Users have no
need to engage with these directly.

- [`raceinfo()`](https://jenslemb.github.io/cyclingdata/reference/raceinfo.md)
  : Scrape race information from procyclingstats.com.
- [`racedata()`](https://jenslemb.github.io/cyclingdata/reference/racedata.md)
  : Scrape stage data from procyclingstats.com.
- [`raceyears()`](https://jenslemb.github.io/cyclingdata/reference/raceyears.md)
  : List of years where races were completed.
- [`racenames()`](https://jenslemb.github.io/cyclingdata/reference/racenames.md)
  : Convert race identifier to full names.
- [`raceurlkey()`](https://jenslemb.github.io/cyclingdata/reference/raceurlkey.md)
  : Convert race identifiers to URL key
- [`checkrace()`](https://jenslemb.github.io/cyclingdata/reference/checkrace.md)
  : Check whether a race was completed in a given year.
